**Category:** General Skills

## Description
The challenge requires converting the decimal number 42 into its binary representation.

## My Approach
I wrote a C program using the `%b` format specifier in `printf` to directly convert and display the decimal value as a binary string 

## Concepts Learned
- **C23 Standards:** Utilizing modern C features like the binary format specifier for direct base conversion.
- **Data Types:** Managing small integer values within a `char` type to optimize memory usage.
- **Binary Representation:** Verifying the bit pattern of common decimal integers used in low-level computing.

## Solution
The implementation is saved in `convert.c` and can be compiled with `gcc`.
