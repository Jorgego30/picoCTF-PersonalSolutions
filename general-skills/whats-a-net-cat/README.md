# What's a Net Cat? 🐱🌐

**Category:** General Skills

## Description
This challenge introduces the use of the `nc` (Netcat) utility. The goal is to connect to a specific host and port to retrieve the flag from a remote server.

## My Approach
To solve this picoCTF exercise, I used the `nc` command. Instead of using a web browser or SSH, I needed a direct TCP connection to the provided address.

## Concepts Learned
- **Netcat (`nc`):** A powerful networking utility used for reading from and writing to network connections using TCP or UDP.
- **Ports and Hosts:** Understanding how to target a specific service running on a remote server using its hostname and port number.
